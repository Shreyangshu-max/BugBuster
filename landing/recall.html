Why does while (lo < hi) skip the last element in binary search?

When lo equals hi, the target element at index lo has not been evaluated yet. If the loop terminates when lo == hi, what condition should be used? 

# Your previous submission had this mistake:
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo < hi: # ❌ Exits when lo == hi without checking nums[lo]
        mid = (lo + hi) // 2
        ...

Correct Pattern & Explanation:

Use while (lo <= hi) when your search space includes both boundaries [lo, hi]. Alternatively, if using lo < hi, handle the single remaining element after the loop terminates.
